# Project Market (робоча назва)

Маркетплейс нереалізованих креативних студентських проєктів. Повний
контекст — у [`CLAUDE.md`](./CLAUDE.md) (читається на початку кожної
сесії) і в [`docs/strategy/`](./docs/strategy) (концепція, дорожня
карта, фінансова модель, персони користувачів, дослідження ринку).

## Що вже зроблено

**Етап 1 — технічний фундамент**
- Проєкт на **Next.js** (React + TypeScript) — сучасний, широко
  вживаний стек, зручний для швидкого старту у вебі й майбутнього
  переходу на мобільні застосунки.
- Дизайн-система: кольори, шрифти (**Unbounded** для заголовків,
  **Manrope** для тексту) і базові компоненти (кнопки, бейджі
  статусів, картка проєкту) — усе за напрямом з `CLAUDE.md`.
- Демо-сторінка `/style-guide` — щоб побачити весь візуальний напрям
  на одному екрані, перш ніж будувати реальні сторінки.

**Етап 2 — ядро даних**
- Схема бази даних: автори, проєкти, файли проєктів — див.
  [`docs/data-model.md`](./docs/data-model.md) (простими словами) або
  [`prisma/schema.prisma`](./prisma/schema.prisma) (технічно).
- Ще не підключено до реальної бази — це наступний крок.

**Етап 3 — автентифікація і профілі**
- Реєстрація/вхід через Google, Apple або email+пароль; онбординг:
  вибір ролі (Творець/Отримувач) і, для Творця, основного напряму;
  захищена сторінка профілю — див. [`docs/auth.md`](./docs/auth.md)
  простими словами.
- Google/Apple поки не запрацюють наживо — потрібні ключі від вас
  (кроки в `docs/auth.md`).

**Етап 4 — завантаження і картка проєкту**
- Форма завантаження проєкту для напряму "Архітектура": усі поля з
  вашого запиту (тип об'єкта — 11 варіантів, стиль архітектури — 25 + 3
  службові, опис до 1000 символів, хештеги, дві незалежні ціни, файли до
  21 МБ з попереднім переглядом) — простими словами в
  [`docs/project-upload.md`](./docs/project-upload.md).
- Сторінка перегляду проєкту — з усіма полями, галереєю файлів і
  службовими тегами для пошуку в Google (хештеги).
- Рішення про оплату $1 за перегляд контактів записано в `CLAUDE.md`, але
  сам код — Етап 6 ("Угода"), ще попереду.

**Етап 5 — пошук і фільтри**
- Головна сторінка тепер — стрічка проєктів з нескінченною прокруткою
  (довантажується сама при гортанні вниз), а не заглушка Етапу 1.
- Простий пошук (за назвою/описом/хештегом) і сортування — доступні всім,
  включно з незалогіненими відвідувачами.
- Панель детальних фільтрів (тип об'єкта, стиль, ціна, площа, поверховість,
  рік, софт, статус) — тільки для Отримувача, як і домовились; простими
  словами — [`docs/search-and-filters.md`](./docs/search-and-filters.md).

**Етап 6 — угода**
- Профіль тепер можна редагувати будь-коли після заповнення анкети (кнопка
  "Редагувати профіль"), і в ньому зʼявились два необов'язкові контакти —
  Telegram і WhatsApp.
- На сторінці проєкту — оплата 40 ₴ за перегляд контактів автора (телефон,
  email, Telegram, WhatsApp), з режимом миттєвої тестової оплати, доки не
  підключено справжній LiqPay-акаунт; простими словами —
  [`docs/payments.md`](./docs/payments.md).
- "Обране" — і Творець, і Отримувач можуть зберегти собі будь-який проєкт
  (серце на картці чи на сторінці проєкту) і знайти його пізніше в розділі
  "Обране".
- Автор проєкту тепер сам може змінити його статус (Навчальний → Концепт →
  На продаж → Продано → У розробці → Реалізовано → В архіві) прямо на
  сторінці проєкту.

## Як це подивитись

Найпростіше — я надсилаю знімок екрана прямо в чат щоразу, коли є що
показати. Якщо захочете подивитись самостійно наживо, знадобиться,
щоб хтось (я або ваш син) запустив дві команди в терміналі:

```bash
npm install   # один раз — завантажує потрібні бібліотеки
npm run dev   # запускає сайт на http://localhost:3000
```

Вам самим нічого з цього робити не потрібно — це для довідки.

## Структура проєкту (коротко)

```
src/app/               сторінки сайту (Next.js App Router)
src/app/page.tsx       стрічка проєктів (пошук/фільтри, Етап 5)
src/app/api/projects/  довантаження наступних сторінок стрічки
src/components/ui/     перевикористовувані елементи інтерфейсу
src/lib/               допоміжний код (шрифти, утиліти, підключення до бази)
src/lib/validation/    Project DNA — структуровані поля по вертикалях
src/lib/projects/      запит і доступ до стрічки й обраного (Етапи 5-6)
src/lib/payments/      оплата за перегляд контактів — LiqPay (Етап 6)
src/lib/storage.ts     тимчасове сховище файлів проєктів (локальний диск)
prisma/schema.prisma   схема бази даних
docs/strategy/         усі стратегічні документи проєкту
docs/data-model.md     ядро даних простими словами
docs/project-upload.md форма завантаження проєкту простими словами
docs/search-and-filters.md пошук і фільтри простими словами
docs/payments.md       оплата за перегляд контактів простими словами
```
