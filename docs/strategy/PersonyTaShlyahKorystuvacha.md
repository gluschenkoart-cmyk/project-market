**Навіщо цей документ**

Усі попередні документи описували систему: вертикалі, метадані,
монетизацію, ринок. Жоден не показував живу людину, яка відкриває
застосунок вперше. Цей документ закриває саме цю прогалину --- і
використовує персон не як ілюстрацію, а як перевірку: чи справді
структура, яку ми вже затвердили, витримує зіткнення з реальною
поведінкою.

**АВТОР 1 З 5**

+-----------------------------------------------------------------------+
| **АРХІТЕКТУРА**                                                       |
|                                                                       |
| **Марія Коваль, 22 роки**                                             |
|                                                                       |
| *5 курс, КНУБА, спеціальність 191 · Київ*                             |
+-----------------------------------------------------------------------+

**Ситуація:** Дипломний проєкт «Житловий комплекс для студентського
містечка» готовий, захист --- за два місяці. Науковий керівник хвалить,
комісія оцінить, а далі файл ляже в папку «Диплом_фінал_v14», яку більше
ніхто не відкриє.

**Мотивація:** Не гроші в першу чергу --- видимість. Хоче, щоб роботу
побачили поза межами трьох членів комісії. Дохід --- приємний бонус, не
головна мета.

***«Я півроку рахувала навантаження на перекриття. Після захисту цей
файл більше ніхто не відкриє.»***

  ------- -----------------------------------------------------------------
  **1**   **Дізнається ---** викладач згадує платформу на парі, або
          однокурсник ділиться посиланням

  **2**   **Реєструється ---** вказує ПІБ, телефон, повну назву ВУЗу
          (КНУБА), факультет; підтверджує самостійну відповідальність за
          авторське право

  **3**   **Завантажує проєкт ---** вертикаль «Архітектура»; заповнює
          Project DNA --- тип, площа, поверховість, рік, статус «Academic»;
          завантажує рендери, плани, 3D-модель

  **4**   **Прикріплює статтю ---** додає наукову статтю (фактично ---
          доопрацьовану пояснювальну записку до диплому) як матеріал,
          привʼязаний до проєкту

  **5**   **Встановлює ціну ---** вагається між «лише портфоліо» і
          продажем; зрештою ставить помірну ціну --- хоче перевірити, чи
          механізм взагалі працює

  **6**   **Публікується ---** проєкт проходить базову модерацію,
          зʼявляється в пошуку за фільтрами Project DNA

  **7**   **Отримує контакт ---** девелопер з Польщі, що шукав «житло,
          5000--8000 м², Європа», знаходить проєкт через фільтри й пише
          напряму

  **8**   **Продає ---** угода закрита, платформа бере 5%; статус
          змінюється на «Sold/Licensed»

  **9**   **Через рік --- «Built» ---** девелопер починає реалізацію на
          основі концепту; статус проєкту оновлюється на «Built» ---
          найсильніша можлива історія для стрічки й PR
  ------- -----------------------------------------------------------------

**АВТОР 2 З 5**

+-----------------------------------------------------------------------+
| **ОБРАЗОТВОРЧЕ МИСТЕЦТВО**                                            |
|                                                                       |
| **Олексій Гриценко, 24 роки**                                         |
|                                                                       |
| *випускник художньої академії (2 роки тому) · працює не за фахом*     |
+-----------------------------------------------------------------------+

**Ситуація:** Продовжує писати картини вечорами, продає зрідка знайомим
чи на локальних ярмарках за символічні гроші. На відміну від Марії, тут
немає «одного диплома» --- є постійний потік нових робіт без системного
каналу продажу.

**Мотивація:** Стабільний канал, не разова видимість. Головне --- щоб
кожна нова робота автоматично мала шанс знайти покупця, а не губилась
серед стрічки друзів в Instagram.

***«Instagram показує мою роботу друзям. Тут я хочу, щоб її побачив
хтось, готовий заплатити.»***

  ------- -----------------------------------------------------------------
  **1**   **Дізнається ---** не через виш (він уже випускник) --- через
          спільноту художників у соцмережах

  **2**   **Реєструється ---** вказує виш, де навчався, навіть постфактум
          --- платформа не обмежена лише поточними студентами

  **3**   **Завантажує роботу ---** вертикаль «Образотворче мистецтво»;
          техніка (олія на полотні), розмір, рік, тип (оригінал)

  **4**   **Архів росте ---** поступово завантажує весь корпус робіт за
          останні два роки --- цінність саме в архіві, що накопичується, а
          не в одній публікації

  **5**   **Встановлює ціну ---** сам вирішує вартість кожної картини ---
          без нав'язаних рівнів ліцензії

  **6**   **Отримує соціальний відгук ---** лайки й підписники
          (Instagram-шар) ще до першого продажу --- підтримує мотивацію
          лишатись на платформі

  **7**   **Перший продаж ---** дизайнер інтер'єрів, що шукав «живопис,
          теплі тони, 100×150 см», купує роботу

  **8**   **Стає постійним автором ---** цикл повторюється з кожною новою
          роботою --- платформа стає постійним каналом, а не одноразовою
          дією
  ------- -----------------------------------------------------------------

**АВТОР 3 З 5**

+-----------------------------------------------------------------------+
| **СКУЛЬПТУРА**                                                        |
|                                                                       |
| **Дарина Мельник, 27 років**                                          |
|                                                                       |
| *скульпторка-фрилансерка, 3 роки після випуску*                       |
+-----------------------------------------------------------------------+

**Ситуація:** Кілька завершених робіт стоять у майстерні. Фізичну
скульптуру продати онлайн складніше, ніж картину, --- покупець має
зрозуміти обʼєм, вагу, можливість перевезення, а не лише побачити фото.

**Мотивація:** І дохід, і громадська позиція. Активно цікавиться темою
знищення памʼяток культурної спадщини і хоче про це писати, не лише
продавати.

***«Скульптуру не можна просто «відправити файлом». Покупець має
зрозуміти вагу, розмір, як це взагалі привезти.»***

  ------- -----------------------------------------------------------------
  **1**   **Дізнається ---** через професійну спільноту скульпторів

  **2**   **Завантажує роботу ---** вертикаль «Скульптура»; матеріал
          (бронза), висота, вага, наклад/edition, indoor/outdoor --- саме
          тому ці поля виділені окремо від живопису

  **3**   **Пише самостійну статтю ---** публіцистична стаття без прив'язки
          до конкретного проєкту, з архівними фото --- тема «знищення
          памʼятки архітектури» в її місті, рубрика «охорона й втрата
          спадщини»

  **4**   **Стаття модерується ---** редакторська перевірка (не наукова
          рецензія --- це публіцистичний, а не науковий текст)

  **5**   **Отримує впізнаваність ---** стаття підвищує довіру до профілю
          ще до першого продажу скульптури

  **6**   **Покупця приводить стаття ---** галерея знаходить її саме через
          статтю, а не через маркетплейс-пошук --- контент став каналом
          залучення покупця

  **7**   **Домовляється окремо ---** логістику доставки погоджує з
          покупцем поза платформою; платформа звела сторони й забезпечила
          угоду з комісією 5%
  ------- -----------------------------------------------------------------

**АВТОР 4 З 5**

+-----------------------------------------------------------------------+
| **ДИЗАЙН**                                                            |
|                                                                       |
| **Ігор Савчук, 23 роки**                                              |
|                                                                       |
| *магістр промислового дизайну · захистився 3 місяці тому*             |
+-----------------------------------------------------------------------+

**Ситуація:** Розробив концепт модульних меблів для курсової --- якісний
CAD-файл, рендери, робочі креслення. Після захисту --- та сама доля, що
і в Марії: файл, який більше не відкриють.

**Мотивація:** Не хоче йти у фриланс-конвеєр на кшталт Upwork. Хоче, щоб
саме цю розробку побачив виробник і зробив її реальним продуктом.

***«Я не хочу бути меблевим дизайнером-фрилансером на біржі. Я хочу, щоб
хтось побачив саме цю розробку і зробив її реальною.»***

  ------- -----------------------------------------------------------------
  **1**   **Реєструється й завантажує ---** вертикаль «Дизайн»; тип
          (меблі), формат файлу, ліцензія використання, софт, виробничі
          файли (DWG/STEP)

  **2**   **Встановлює ціну ---** закладає в ціну саме ліцензію на
          виробництво, не одноразовий перегляд файлу

  **3**   **Індексується за фільтрами ---** потрапляє в пошук за категорією
          «продукт-дизайн», типом меблів, матеріалом

  **4**   **Виробник знаходить проєкт ---** меблева компанія шукає готові
          концепти для виробництва --- саме така поведінка, яку не покриває
          жоден фриланс-майданчик

  **5**   **Купує ліцензію ---** на виробництво, з можливістю зв'язатись з
          автором для доопрацювання

  **6**   **Ігор консультує ---** за додаткову домовленість поза базовою
          угодою --- перший крок до довшої співпраці з виробником
  ------- -----------------------------------------------------------------

**АВТОР 5 З 5**

+-----------------------------------------------------------------------+
| **ЦИФРОВЕ МИСТЕЦТВО / 3D / АНІМАЦІЯ**                                 |
|                                                                       |
| **Тимур Бондаренко, 20 років**                                        |
|                                                                       |
| *2 курс школи гейм-дизайну (не класичний університет)*                |
+-----------------------------------------------------------------------+

**Ситуація:** Зробив rigged 3D-модель фентезійного персонажа з короткою
анімацією для курсової. Викладав лише на особистому акаунті в
спеціалізованій мережі, де загубився серед мільйонів робіт.

**Мотивація:** Ранній дохід і видимість у вузькій індустрії геймдеву ---
задовго до випуску, не після нього.

***«На своєму акаунті мене ніхто не бачить. Тут хоча б є фільтр саме на
те, що я вмію робити.»***

  ------- -----------------------------------------------------------------
  **1**   **Дізнається ---** не через виш --- через спеціалізовану
          Discord-спільноту гейм-розробників; це зовсім інший канал, ніж в
          архітектора

  **2**   **Реєструється ---** вказує «школа гейм-дизайну» замість
          класичного університету --- підтверджує, що поле «навчальний
          заклад» має бути гнучким, не лише для університетів

  **3**   **Завантажує роботу ---** вертикаль «Цифрове
          мистецтво/3D/Анімація»; тип (rigged character + анімація), софт
          (Blender), поліконт, формат файлу, ліцензія (game-ready)

  **4**   **Встановлює ціну ---** вища, ніж середня картина --- game-ready
          3D-моделі мають вищу ринкову вартість за замовчуванням

  **5**   **Покупець --- інді-студія ---** команда з 4 людей шукає готового
          rigged-персонажа для прототипу гри замість замовлення з нуля

  **6**   **Продає ліцензію ---** отримує перший дохід ще на 2 курсі ---
          задовго до випуску, на відміну від усіх інших персон
  ------- -----------------------------------------------------------------
